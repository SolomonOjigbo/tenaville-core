## Before public use

"Tenaville" is a **working name**. PRD Appendix A and §11 require, before any public use:

- CAC business-name register check and a Nigerian trademark search
- `.com`, `.ng` and `.com.ng` domains, social handles, app-store listings
- Saying the name aloud to five agents and asking them to write it down

Appendix A also flags two specific risks: a struck-off Cyprus company of the same name, and a resemblance to an existing hygiene brand that a trademark adviser should assess.

Treat the name as replaceable. Keep it in content and configuration — not in database identifiers, package names or asset filenames that would be painful to rename. Tracked as [open decision 19](../docs/ops/open-decisions.md).
